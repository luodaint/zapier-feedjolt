# zapier-feedjolt

Zapier Platform CLI integration for [Feedjolt](https://www.feedjolt.com).

- Auth: workspace API key (`fjk_…`) as `Authorization: Bearer`
- Base URL: `https://api.feedjolt.com/api/v1`
- OpenAPI: https://api.feedjolt.com/openapi.json

Scaffold with `zapier-platform` (Node 22). Do not commit secrets.
